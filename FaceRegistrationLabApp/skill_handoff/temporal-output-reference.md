# SpatialML temporal geometry and final-output integration

Apply these rules when a spatial inference result is registered into a world/Stage frame, filtered, read back or uploaded to a dynamic scene. Treat SDK APIs, camera origins and measured timings as version-specific.

1. Establish a per-frame contract: source image size/affine, effective K, model/crop transform, optical-camera pose, capture timestamp, Stage/head pose, output selection, configuration revision and terminal completion. Keep this tuple coherent across inference, readback, rendering and export.
2. Calibrate source-camera rays independently of registration residuals. Verify source-to-working image conversion with `K_work = A × K_source`; apply A once. Freeze source K before fitting an effective registration. Use measured rigid targets, independently anchored physical corner identities, held-out views/distances and multiple rotation axes. Face anatomy is a separate validation signal and may differ by subject.
3. Verify units and spaces from actual output tensors. Convert centimetres to metres once. Apply capture-head compensation at the exposure timestamp. In this case `Q_stage = H_capture × D × E × Q_camera_metres`. Preserve inference similarity scale separately from camera-ray scale. Apply the same pose/vertex transform, and undo the complete rigid transform for raw references. Do not apply face pose twice to vertices already in camera space.
4. Treat a fixed millimetre offset that works near and fails far as evidence to examine ray direction, origin and rotation. Do not invent a distance correction curve or jointly tune K/E/D/face scale solely to minimize rendered face residuals. An effective stereo registration is not automatically factory calibration.
5. Follow the model's video tracking behavior. Acquire with the detector, then use valid landmark ROI history; reacquire on loss or incompatible configuration. Keep diagnostics that require detector-per-frame behavior explicitly separated. Track-episode counters are not counts of distinct people.
6. Filter after capture-time compensation in the stable Stage/world frame. Remove raw translation/quaternion/scale before filtering local facial shape. Reconstruct the mesh using the same filtered pose exposed to app consumers. Avoid mixing a filtered pose with current camera-space vertices. Keep presentation copies separate from measured packets and calibration exports.
7. Use capture-time deltas, coherent velocity and signed quaternion-vector derivatives. Keep strong static damping with faster response to sustained motion. Evaluate static noise, movement onset, turns, expressions, stops/reversals, varied rates, Stage-axis invariance and simulated headset motion. Reset on identity/configuration/topology changes, loss and time gaps. Confirm isolated same-track jumps with bounded holding and label held output explicitly.
8. Preserve the internal geometry pose when a mesh-only consumer disables public pose output. Keep absent public outputs empty, but retain the internal state required to render/filter a requested mesh. Test mode transitions as well as all-output mode.
9. Fence terminal publication before reading a final snapshot. Validate exact sequence, schema/length, selection and configuration. A current leading sequence is insufficient when the packet tail may still be written. Shared memory does not prove atomic publication or zero-copy. Count small polling reads/maps/calls as well as final bytes.
10. Keep one mutable inference frame and one native upload in flight until independent buffer ownership and fences are proven. Complete a started replacement; conflate pending display work to the newest completed frame. Keep exact calibration acknowledgements. Do not let fast inference repeatedly cancel an in-flight native mesh write.
11. Measure paired boundaries: submission→readback, camera age at readback, decode/registration, filtering, publication/queue wait, coordinate conversion, preparation, native replacement and upload acknowledgement. Separate startup/no-face/acquisition/tracking/diagnostics/output masks. Do not add stage medians/p95 values or double-count intervals. SDK upload acknowledgement is not compositor presentation, and filter response lag is not the same as elapsed upload time.
12. Optimize actual traffic and unnecessary work. Compact final packets may be cheap while a full camera image is copied/cast for every model call. Byte-first sampling, bounded same-exposure tiles, supported shared buffers, optional heads and fewer completion calls are candidates. Verify pixel/K/affine/timestamp equivalence and full-path gains. A faster preprocessing kernel can coexist with unchanged or worse end-to-end latency.
13. Inspect dynamic rendering separately. Prepare numeric mesh data off the UI path when SDK thread contracts permit; omit normals for unlit materials when legal; reuse topology/buffers; cache owner conversion only with reliable invalidation. A local mesh plus pose transform can avoid full-mesh uploads for rigid motion. These are candidates until the substage timings and API contracts are verified.
14. Preserve accepted user results. Make filter/control changes reversible, retain measured data, checkpoint before major experiments and verify installed APK hashes. Inspect shared service clients under a scoped device lease before a necessary restart. A missing private file can print an error with exit code zero; parse content/error text. Record startup/GPU allocation failures separately from successful frame timings.
